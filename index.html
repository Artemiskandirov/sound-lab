Звук и вибро на одной шкалевибро повторяет огибающую

Пунктиром отмечены границы вызовов navigator.vibrate: спецификация ограничивает паттерн десятью записями, поэтому длинная дорожка выдаётся несколькими вызовами встык — иначе всё, что дальше десятой записи, браузер отбрасывает, и вибро обрывается в самом начале. Оранжевые риски снизу — щелчки переключателя для iPhone: там длительной вибрации нет как примитива, и она собирается из них. Цвет отрезков — яркость звука на этом участке: фиолетовое глухое, оранжевое звонкое. Яркость входит в силу, а сила и есть частота щелчков, поэтому гонг ощущается крупным зерном раз в 56 мс, а свисток — гладким раз в 16 мс.

Вибро в браузередвижок web-haptics

Движок здесь — порт web-haptics Лохи Экcона (MIT). Там, где есть navigator.vibrate, играет он, а сила имитируется широтно-импульсной модуляцией: импульс режется на окна по 20 мс, доля включённого равна силе. Там, где его нет (все браузеры на iPhone — они все на WebKit), вибрация складывается из щелчков системного переключателя <input type="checkbox" switch>: интервал между щелчками равен 16 + (1−сила)·184 мс, то есть на полной силе щелчок каждый кадр. Сверху добавлена нарезка на куски по десять записей — спецификация Vibration API задаёт «Let max length have the value 10» и обрезает остальное.

Песочница—

У каждого элемента свой звук и синхронное вибро: оба запускаются из одного обработчика жеста. Это не украшение — Vibration API требует пользовательской активации, а в Safari системный хаптик срабатывает только в момент касания, поэтому любая задержка между жестом и вызовом ломает вибрацию.
